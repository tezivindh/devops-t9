# Session 1: DevOps Engineer Roadmap & Overview

## Overview
In this introductory session, we covered what DevOps is, why companies adopt it, and the complete roadmap of skills needed to become a DevOps engineer.

---

## 1. What is DevOps?
DevOps is a set of practices, culture, and tools that bridges the gap between software development (Dev) and IT operations (Ops). 
- **Traditional approach**: Developers wrote code and tossed it over the wall to Operations, leading to deployment delays and finger-pointing when things broke.
- **DevOps approach**: Shared responsibility, automated pipelines, faster feedback loops, and smaller, frequent releases.

---

## 2. The DevOps Lifecycle & Key Phases

```text
[ Plan ] ➔ [ Code ] ➔ [ Build ] ➔ [ Test ] ➔ [ Release ] ➔ [ Deploy ] ➔ [ Operate ] ➔ [ Monitor ]
```

1. **Plan**: Requirements gathering, backlog tracking, agile sprints (Jira, Trello).
2. **Code**: Version control and code collaboration (Git, GitHub, GitLab).
3. **Build**: Compiling code and packaging artifacts (Maven, npm, Docker).
4. **Test**: Automated unit, integration, and security testing (JUnit, SonarQube).
5. **Release & Deploy**: Continuous delivery and automated deployment to servers or cloud (Jenkins, GitHub Actions, ArgoCD).
6. **Operate**: Infrastructure management and container orchestration (Linux, Kubernetes, Terraform).
7. **Monitor**: Tracking application health, metrics, and logs in production (Prometheus, Grafana, ELK Stack).

---

## 3. Key Skills & Tool Roadmap Covered in this Course
- **Linux & Shell Scripting** (Sessions 2 & 3): Core operating system commands, permissions, process management, and automating tasks with Bash scripts.
- **Computer Networking** (Session 4): IP addressing, subnets, routing, DNS, and network troubleshooting tools (`ping`, `curl`, `ss`, `ip`).
- **Git & GitHub** (Session 5): Branching strategies, staging area, commit history, and `cherry-pick`.
- **Docker & Containerization** (Sessions 6, 7 & 8): Packaging applications with Dockerfiles, multi-stage builds, container networks, and volume bind mounts.
- **Kubernetes** (Sessions 9 & 10): Container orchestration, Pods, Deployments, ReplicaSets, and Services.
